> **OffGrid** est une application iOS de résilience et de sécurité personnelle conçue pour fonctionner en zone blanche ou situation d'urgence, sans connexion internet ni réseau mobile.

---

## 📲 Téléchargement Direct & Installation

Téléchargez la dernière version compilée sur la page [**Releases GitHub**](https://github.com/je-tu-il/Guardian-Phone/releases/latest) :

1. Téléchargez le fichier **`OffGrid.ipa`**.
2. Installez-le avec votre utilitaire de sideloading favori :
   - 🍏 **AltStore / SideStore** : Onglet *My Apps* > bouton `+` > sélectionnez `OffGrid.ipa`.
   - 💻 **Sideloadly** : Glissez `OffGrid.ipa` et lancez l'installation en USB.
   - ⚡ **TrollStore** : Installation directe sans contrainte de certificat.

---

## ✨ Fonctionnalités Clés

- 🚨 **Boussole Tactique & Coordonnées GPS Hors-Ligne** : Affichage instantané de la latitude, longitude, altitude et relèvement magnétique sans requête réseau.
- 🔦 **Mode Balise de Détresse (SOS Strobe & Audio)** :
  - Clignotement flash Morse international SOS (`... --- ...`).
  - Signal sonore strident haute fréquence pour localisation par les secours.
- 📡 **Fiche d'Urgence Autonome** : Stockage local crypté de vos informations vitales (groupe sanguin, allergies, contacts d'urgence) accessible en 1 clic.
- 🧰 **Guide de Survie & Premiers Secours Embarqué** : Fiches pratiques illustrées directement embarquées dans l'application pour agir vite même sans réseau.

## 🛠️ Stack Technique

- **Langage** : Swift 5.9+ / SwiftUI
- **Frameworks** : CoreLocation, AVFoundation, CoreHaptics
- **Cible** : iOS 17.0+ (iPhone)
- **CI/CD** : GitHub Actions (compilation Release IPA sous macOS)
